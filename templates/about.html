How FakeGuard Works

Understanding the machine learning pipeline behind our fake news detection system

1. Text Preprocessing

The raw text is cleaned and normalized. This includes converting to lowercase, removing stopwords and tokenization.

2. TF-IDF Vectorization

TF-IDF converts text into numerical vectors capturing word importance.

3. Classification Model

Passive Aggressive classifier analyzes patterns to classify news.

4. Prediction Output

System predicts REAL or FAKE with confidence score.

Detection Flow

Input Text → Preprocessing → Tokenization → TF-IDF → Classifier → Prediction
